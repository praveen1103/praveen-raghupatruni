Core Concepts
Understanding the RxJS mental model
Observable
A lazy push-based data producer. Starts emitting only when subscribed. The foundation of all RxJS streams.
Observer
Consumer of Observable values. Has three callbacks: next, error, and complete.
Subscription
Represents an Observable execution. Call .unsubscribe() to cancel and free resources.
Operator
Pure functions that enable functional-style transformations. Used inside pipe() to compose behaviour.
typescript
import { Observable, Subject, BehaviorSubject } from 'rxjs';
import { map, filter, switchMap, catchError } from 'rxjs/operators';

// Create an Observable
const obs$ = new Observable<number>(subscriber => {
  subscriber.next(1);
  subscriber.next(2);
  subscriber.complete();
});

// Compose operators with pipe()
obs$.pipe(
  filter(n => n > 1),
  map(n => n * 10)
).subscribe({
  next:     val  => console.log(val),   // 20
  error:    err  => console.error(err),
  complete: ()   => console.log('Done')
});

Creation Operators
Create new Observables from various data sources
10 operators
of(...values) Synchronous ›

Emits a finite list of values synchronously, then completes. Perfect for converting static values or returning defaults in services.

Angular Example
typescript
import { of } from 'rxjs';
import { catchError } from 'rxjs/operators';

// Return a default value when API fails
getUser(id: number): Observable<User> {
  return this.http.get<User>(`/api/users/${id}`).pipe(
    catchError(() => of({ id: 0, name: 'Guest', role: 'viewer' }))
  );
}

// Emit multiple static values
of(1, 2, 3, 'Angular', true).subscribe(val => console.log(val));
Emits: 1, 2, 3, 'Angular', true — then completes
from(source) Array / Promise / Iterable ›

Converts an Array, Promise, iterable, or another Observable into an Observable. One of the most versatile creation operators.

Angular Example
typescript
import { from } from 'rxjs';
import { mergeMap } from 'rxjs/operators';

// From an Array — emit each element
from([10, 20, 30]).subscribe(console.log);   // 10, 20, 30

// From a Promise (e.g. native fetch)
from(fetch('/api/profile').then(r => r.json()))
  .subscribe(profile => this.profile = profile);

// Upload multiple files
uploadAll(files: File[]) {
  return from(files).pipe(
    mergeMap(file => this.upload.send(file))
  );
}
Emits each array element / Promise resolution sequentially
interval(periodMs) Infinite / Timer ›

Creates an Observable that emits sequential integers (0, 1, 2...) at a specified interval. Runs indefinitely — always combine with takeUntil.

Angular Example
typescript
import { interval, Subject } from 'rxjs';
import { takeUntil, switchMap } from 'rxjs/operators';

@Component({ ... })
export class LiveDashboardComponent implements OnDestroy {
  private destroy$ = new Subject<void>();

  ngOnInit() {
    interval(5000)                       // every 5 seconds
      .pipe(
        switchMap(() => this.statsService.getMetrics()),
        takeUntil(this.destroy$)        // auto-cleanup
      )
      .subscribe(metrics => this.metrics = metrics);
  }

  ngOnDestroy() { this.destroy$.next(); this.destroy$.complete(); }
}
Polls every 5s, stops automatically when component destroys
timer(delay, period?) Delayed / Periodic ›

Waits an initial delay before emitting, then optionally continues at a fixed interval. Useful for deferred one-shot actions or delayed polling.

Angular Example
typescript
import { timer } from 'rxjs';
import { switchMap, takeUntil } from 'rxjs/operators';

// One-shot: auto-dismiss notification after 3s
showNotification(msg: string) {
  this.notification = msg;
  timer(3000).subscribe(() => this.notification = null);
}

// Delayed polling: start after 3s, then every 10s
startPolling() {
  timer(3000, 10000)
    .pipe(switchMap(() => this.api.getStatus()),
           takeUntil(this.destroy$))
    .subscribe(status => this.status = status);
}
Notification cleared after 3s; polling begins after 3s delay, then repeats every 10s
fromEvent(target, event) DOM / Node Events ›

Creates an Observable from DOM events, Node.js EventEmitters, or anything event-like. Pairs perfectly with debounceTime for search inputs.

Angular Example
typescript
import { fromEvent } from 'rxjs';
import { debounceTime, map, distinctUntilChanged } from 'rxjs/operators';

@Component({ template: '<input #searchBox />' })
export class SearchComponent implements AfterViewInit {
  @ViewChild('searchBox') box!: ElementRef;

  ngAfterViewInit() {
    fromEvent<InputEvent>(this.box.nativeElement, 'input')
      .pipe(
        map(e => (e.target as HTMLInputElement).value),
        debounceTime(350),
        distinctUntilChanged(),
        takeUntil(this.destroy$)
      )
      .subscribe(query => this.search(query));
  }
}
API search triggered only after 350ms pause with a new value

Transformation Operators
Transform emitted values into new shapes
11 operators
map(projectionFn) Core Transform ›

Applies a projection function to each emitted value. The most fundamental transformation — mirrors Array.prototype.map.

Angular Example
typescript
import { map } from 'rxjs/operators';

getUsers(): Observable<User[]> {
  return this.http.get<ApiResponse>('/api/users').pipe(
    map(res => res.data),                      // unwrap nested data
    map(users => users.map(u => ({           // transform each
      ...u,
      fullName: `${u.firstName} ${u.lastName}`,
      isAdmin: u.role === 'ADMIN'
    })))
  );
}
Each user object enriched with fullName and isAdmin properties
switchMap(project) Cancels Previous ›

Maps each value to an Observable, cancelling the previous inner subscription when a new source value arrives. The go-to for search and navigation — only the latest matters.

Angular Example
typescript
import { switchMap, debounceTime, distinctUntilChanged } from 'rxjs/operators';

@Component({ ... })
export class ProductSearchComponent {
  searchControl = new FormControl('');

  results$ = this.searchControl.valueChanges.pipe(
    debounceTime(300),
    distinctUntilChanged(),
    switchMap(query =>          // cancels previous request
      query?.trim()
        ? this.productService.search(query)
        : of([]))
  );
}
Only the latest search HTTP request is active — previous ones auto-cancelled
mergeMap(project) Concurrent ›

Maps each value to an Observable and merges all resulting Observables concurrently. Also called flatMap. Use when order doesn't matter and you need maximum parallelism.

Angular Example
typescript
import { from } from 'rxjs';
import { mergeMap, toArray } from 'rxjs/operators';

// Upload multiple files simultaneously
uploadFiles(files: File[]) {
  return from(files).pipe(
    mergeMap(
      file => this.storage.upload(file),
      3   // concurrency limit: max 3 at once
    ),
    toArray()   // collect all results
  );
}
All uploads run in parallel (max 3 concurrent), results collected into array
concatMap(project) Sequential / Ordered ›

Maps to an Observable and queues them strictly in order — each must complete before the next starts. Use when order is critical (sequential API calls, processing queues).

Angular Example
typescript
import { from } from 'rxjs';
import { concatMap, tap } from 'rxjs/operators';

// Process migration steps in strict order
runMigrations(steps: MigrationStep[]) {
  return from(steps).pipe(
    concatMap(step =>            // step 2 waits for step 1
      this.migrationService.run(step).pipe(
        tap(result => this.log.push(result))
      )
    )
  );
}
Steps execute in strict order; step 2 only begins when step 1 completes
exhaustMap(project) Ignores While Busy ›

Ignores new source values while the current inner Observable is still active. The ideal choice for form submissions — prevents double-submits entirely.

Angular Example
typescript
import { Subject } from 'rxjs';
import { exhaustMap } from 'rxjs/operators';

@Component({ ... })
export class CheckoutComponent {
  private submit$ = new Subject<OrderPayload>();

  ngOnInit() {
    this.submit$.pipe(
      exhaustMap(order =>      // extra clicks ignored
        this.orderService.place(order)
      )
    ).subscribe(result =>
      this.router.navigate(['/confirmation', result.orderId]));
  }

  onSubmit() { this.submit$.next(this.form.value); }
}
Double-clicks and impatient re-submits are silently dropped
scan(accumulator, seed) Running State ›

Like Array.reduce but emits the running accumulation after every value. Perfect for building reactive state from events.

Angular Example
typescript
import { scan, map } from 'rxjs/operators';

// Reactive shopping cart with scan
cart$ = this.cartActions$.pipe(
  scan((items, action) => {
    switch (action.type) {
      case 'ADD':    return [...items, action.item];
      case 'REMOVE': return items.filter(i => i.id !== action.item.id);
      default:       return items;
    }
  }, [] as CartItem[]),
  map(items => ({ items, total: items.reduce((s,i) => s+i.price, 0) }))
);
Cart state and total update reactively with each ADD/REMOVE action

Filtering Operators
Selectively emit values from source
10 operators
filter(predicate) Conditional ›

Only emits items that satisfy the predicate function. The reactive equivalent of Array.prototype.filter.

Angular Example
typescript
import { filter } from 'rxjs/operators';

// Only save valid forms
this.form.valueChanges.pipe(
  filter(() => this.form.valid),    // skip invalid
  debounceTime(500),
  distinctUntilChanged(JSON.stringify)
).subscribe(v => this.autosave(v));

// Skip empty search results
this.http.get<Order[]>('/api/orders').pipe(
  filter(orders => orders.length > 0)
).subscribe(orders => this.orders = orders);
Auto-save only triggered for valid, changed forms
takeUntil(notifier$) Memory Safety ›

Emits values until the notifier Observable emits, then completes and unsubscribes. The canonical Angular pattern for preventing memory leaks.

Angular Example
typescript
import { Subject } from 'rxjs';
import { takeUntil } from 'rxjs/operators';

@Component({ ... })
export class DataComponent implements OnDestroy {
  private destroy$ = new Subject<void>();

  ngOnInit() {
    // All subscriptions cleaned up automatically
    this.dataService.stream$
      .pipe(takeUntil(this.destroy$))
      .subscribe(d => this.data = d);

    interval(1000)
      .pipe(takeUntil(this.destroy$))
      .subscribe(t => this.tick = t);
  }

  ngOnDestroy() {
    this.destroy$.next();     // signal all takeUntils
    this.destroy$.complete();
  }
}
All subscriptions complete when ngOnDestroy fires — zero memory leaks
debounceTime(ms) Rate Control ›

Delays emitting until a specified quiet period has passed after the last emission. Resets the timer if a new value arrives. The essential operator for search inputs.

Angular Example
typescript
import { debounceTime, distinctUntilChanged, switchMap } from 'rxjs/operators';

results$ = this.searchControl.valueChanges.pipe(
  debounceTime(400),              // wait 400ms after last keystroke
  distinctUntilChanged(),         // skip unchanged values
  switchMap(q => this.api.search(q))
);

// Validation feedback with shorter debounce
this.emailControl.valueChanges.pipe(
  debounceTime(200),
  switchMap(email => this.auth.checkEmailTaken(email))
).subscribe(taken => this.emailTaken = taken);
Search fires 400ms after typing stops — saves many unnecessary API calls
distinctUntilChanged(comparator?) Deduplication ›

Suppresses consecutive duplicate emissions. Only emits when the current value differs from the previous. Accepts an optional comparator for deep equality.

Angular Example
typescript
import { distinctUntilChanged, map } from 'rxjs/operators';

// Re-load user only when route ID actually changes
this.route.params.pipe(
  map(p => p['id']),
  distinctUntilChanged()
).subscribe(id => this.loadUser(id));

// Object comparison with custom comparator
this.store.select('user').pipe(
  distinctUntilChanged((a, b) => a.id === b.id && a.role === b.role)
).subscribe(user => this.refreshView(user));
loadUser only called when route ID actually changes, not on repeated navigations

Combination Operators
Combine multiple Observables into one
8 operators
forkJoin([obs1$, obs2$, ...]) Parallel Wait-All ›

Waits for ALL source Observables to complete, then emits an array/object of their last values. The Angular go-to for parallel HTTP requests that must all complete before proceeding.

Angular Example
typescript
import { forkJoin } from 'rxjs';

ngOnInit() {
  this.loading = true;

  forkJoin({                             // named object form
    user:     this.userService.getProfile(),
    orders:   this.orderService.getOrders(),
    settings: this.settingsService.get(),
    flags:    this.featureService.getFlags()
  }).pipe(
    finalize(() => this.loading = false)
  ).subscribe(({ user, orders, settings, flags }) => {
    this.user     = user;
    this.orders   = orders;
    this.settings = settings;
    this.flags    = flags;
  });
}
4 HTTP requests run in parallel; page renders only when all complete
combineLatest([obs1$, obs2$]) Reactive Sync ›

Combines multiple Observables using their latest values, emitting a new array whenever ANY source emits. All sources must have emitted at least once. Great for derived view models.

Angular Example
typescript
import { combineLatest } from 'rxjs';

// Derive view model from multiple sources
viewModel$ = combineLatest([
  this.route.params,
  this.authService.currentUser$,
  this.featureFlags$
]).pipe(
  map(([params, user, flags]) => ({
    resourceId: params['id'],
    canEdit:    user.role === 'ADMIN' && flags.editEnabled,
    canDelete:  user.role === 'ADMIN'
  }))
);
View model re-computed whenever route, user, or flags change
withLatestFrom(obs$) Sample on Trigger ›

When the source emits, combine with the latest value from another Observable. The secondary is only sampled — it doesn't drive emissions.

Angular Example
typescript
import { withLatestFrom } from 'rxjs/operators';

// On save click, grab current form + logged-in user
this.saveClicks$.pipe(
  withLatestFrom(
    this.form.valueChanges,
    this.authService.currentUser$
  )
).subscribe(([_click, formVal, user]) => {
  this.api.save({ ...formVal, updatedBy: user.id });
});
Save always uses latest form values and user context at click time

Error Handling Operators
Handle and recover from errors gracefully
4 operators
catchError(handler) Error Recovery ›

Catches errors on the source and allows you to return a fallback Observable, re-throw selectively, or route to different error flows. Essential for HTTP error handling.

Angular Example
typescript
import { catchError } from 'rxjs/operators';
import { of, EMPTY, throwError } from 'rxjs';

getUser(id: number): Observable<User | null> {
  return this.http.get<User>(`/api/users/${id}`).pipe(
    catchError((err: HttpErrorResponse) => {
      if (err.status === 404)
        return of(null);             // not found → null
      if (err.status === 401) {
        this.auth.logout();
        return EMPTY;               // unauthorized → logout
      }
      return throwError(() => err);  // others → re-throw
    })
  );
}
404 → null; 401 → logout + EMPTY; other errors propagate
retry(count | config) Auto Retry ›

Resubscribes to the source Observable on error, up to N times. In RxJS 7+ accepts a config object for delay and reset-on-success options.

Angular Example
typescript
import { retry, catchError } from 'rxjs/operators';
import { of } from 'rxjs';

fetchCritical() {
  return this.http.get('/api/critical').pipe(
    retry({
      count: 3,
      delay: 1000,                 // 1s between retries
      resetOnSuccess: true
    }),
    catchError(err => {
      this.notif.error('Failed after 3 retries');
      return of(null);
    })
  );
}
Retries 3× with 1s delay; falls back to null after exhausting attempts
finalize(callback) Guaranteed Cleanup ›

Executes a callback when the Observable terminates for ANY reason: completion, error, or unsubscription. The reactive equivalent of finally in try/catch.

Angular Example
typescript
import { finalize, catchError } from 'rxjs/operators';

save(data: FormData) {
  this.saving = true;

  return this.http.post('/api/save', data).pipe(
    catchError(err => {
      this.notif.error(err.message);
      return of(null);
    }),
    finalize(() => this.saving = false)  // ALWAYS runs
  );
}
// Template: <button [disabled]="saving">Save</button>
Spinner/disabled state reset whether save succeeds, errors, or is cancelled

Utility Operators
Toolbox for common Observable tasks
5 operators
tap(observer) Side Effects ›

Performs side effects for each emission without modifying the stream. Perfect for logging, debugging, analytics tracking, and state updates that don't transform data.

Angular Example
typescript
import { tap } from 'rxjs/operators';

getOrders(): Observable<Order[]> {
  return this.http.get<Order[]>('/api/orders').pipe(
    tap(orders => // short-circuit logging
      console.debug(`[Orders] fetched ${orders.length}`)
    ),
    tap(orders => this.analytics.track('orders_loaded', orders.length)),
    tap({                             // full observer form
      next:     v  => this.cache.set(v),
      error:    e  => this.logger.error(e),
      complete: () => this.logger.log('done')
    })
  );
}
Logging, analytics, and caching applied without modifying the Order[] stream
timeout(ms | config) Time Limit ›

Errors if the source doesn't emit within the specified time. Enforces a maximum wait — essential for critical paths where a hung request should fail fast.

Angular Example
typescript
import { timeout, catchError } from 'rxjs/operators';
import { TimeoutError } from 'rxjs';

fetchWithTimeout(url: string) {
  return this.http.get(url).pipe(
    timeout(8000),             // must respond within 8s
    catchError(err => {
      if (err instanceof TimeoutError)
        return of({ error: 'timeout', data: null });
      return throwError(() => err);
    })
  );
}
Fallback response returned if API takes longer than 8 seconds

Multicasting Operators
Share a single subscription among multiple subscribers
3 operators
shareReplay(bufferSize) HTTP Cache ›

Multicasts and replays the last N values to any subscriber — including late ones. The go-to pattern for caching HTTP responses in Angular services.

Angular Example
typescript
import { shareReplay } from 'rxjs/operators';

@Injectable({ providedIn: 'root' })
export class ConfigService {
  // HTTP called ONCE, result cached and replayed to all subscribers
  readonly config$ = this.http
    .get<AppConfig>('/api/config')
    .pipe(shareReplay(1));

  constructor(private http: HttpClient) {}
}

// Any component subscribing later gets cached value immediately
// — no additional HTTP request ever made
@Component({ ... })
export class HeaderComponent {
  config$ = this.configService.config$;  // cached
}
HTTP fetched once at app start; every component reuses the cached value
share() Ref-Counted ›

Multicasts to multiple subscribers using a Subject. Reference-counted — subscribes on first subscriber, unsubscribes when none remain. Unlike shareReplay, does not cache for late subscribers.

Angular Example
typescript
import { share } from 'rxjs/operators';

// Without share: two HTTP requests!
const data$ = this.http.get('/api/data');
data$.subscribe(d => this.view1 = d);   // request 1
data$.subscribe(d => this.view2 = d);   // request 2!

// With share: single HTTP request, two receivers
const shared$ = this.http.get('/api/data').pipe(share());
shared$.subscribe(d => this.view1 = d);   // same request
shared$.subscribe(d => this.view2 = d);   // same request
One HTTP request shared between view1 and view2

Subject Types
Observable + Observer bridge for imperative ↔ reactive
4 types
Type Initial Value Replay to Late Subscribers Best Use
Subject None required No Event bus, cross-component messages
BehaviorSubject Required Last value (1) Current state — auth user, theme, cart
ReplaySubject None Last N values Notification history, audit logs
AsyncSubject None Last value on complete Final computed result
BehaviorSubject(initialValue) State Management ›

Holds the current value and replays it to every new subscriber. The foundation of lightweight reactive state management in Angular without NgRx.

Angular Example
typescript
import { BehaviorSubject } from 'rxjs';
import { map } from 'rxjs/operators';

@Injectable({ providedIn: 'root' })
export class AuthService {
  private userSubject = new BehaviorSubject<User | null>(null);

  // Public read-only stream
  currentUser$  = this.userSubject.asObservable();
  isLoggedIn$   = this.currentUser$.pipe(map(u => u !== null));

  // Synchronous access when needed
  get currentUser(): User | null { return this.userSubject.getValue(); }

  login(user: User)  { this.userSubject.next(user); }
  logout()          { this.userSubject.next(null); }
}
Any component subscribing at any time immediately receives the current auth state

Angular Best Practices
Memory management, async pipe, and patterns
⚡
Prefer the async pipe in templates
The async pipe auto-subscribes and auto-unsubscribes. Using it in templates means zero manual subscription management and zero memory leaks for template-bound streams.
async Pipe Pattern
typescript + template
// service.ts — single source, multiple consumers
@Injectable({ providedIn: 'root' })
export class UserService {
  users$ = this.http.get<User[]>('/api/users').pipe(shareReplay(1));
}

// component.ts — no subscribe/unsubscribe needed!
@Component({
  template: `
    <div *ngIf="vm$ | async as vm">
      <app-user *ngFor="let u of vm.users" [user]="u" />
      <span>Total: {{ vm.count }}</span>
    </div>
    <app-spinner *ngIf="loading$ | async" />
  `
})
export class UserListComponent {
  vm$ = this.userService.users$.pipe(
    map(users => ({ users, count: users.length }))
  );
  loading$ = this.vm$.pipe(map(() => false), startWith(true));
}
takeUntilDestroyed — Angular 16+
typescript
import { takeUntilDestroyed } from '@angular/core/rxjs-interop';
import { DestroyRef, inject } from '@angular/core';

@Component({ ... })
export class ModernComponent {
  // inject in field initializer — no ngOnInit needed
  private destroyRef = inject(DestroyRef);

  ngOnInit() {
    interval(1000).pipe(
      takeUntilDestroyed(this.destroyRef)   // auto cleanup!
    ).subscribe(t => this.tick = t);
    // No ngOnDestroy needed!
  }
}
