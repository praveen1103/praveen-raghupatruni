Install Claude Code & Log In

"Installing software is the developer's version of 'some assembly required.' At least there are no leftover screws." 🪛

Open Windows Terminal (PowerShell is fine) and run the following. This installs the Claude Code CLI globally on your machine. You'll need npm working for this — if it doesn't, go back and install Node.js properly.

PowerShell — install Claude Code
# Install Claude Code CLI globally
npm install -g @anthropic-ai/claude-code

# Verify installation — should print a version number
claude --version

Now set your API key as an environment variable. Do this once and it persists across sessions. Claude Code will pick it up automatically.

PowerShell — set API key
# Set permanently for your user (not just this session)
[System.Environment]::SetEnvironmentVariable(
  "ANTHROPIC_API_KEY",
  "sk-ant-YOUR_KEY_HERE",
  "User"
)

# Reload env vars in current terminal
$env:ANTHROPIC_API_KEY = "sk-ant-YOUR_KEY_HERE"

# Confirm it's set
echo $env:ANTHROPIC_API_KEY
⚠️ Warning: Never paste your API key into a public repo, Discord, or a Teams message to your whole company. We've all seen how that story ends.
✓ Success check: Running claude --version should print something like 1.x.x. If it says "command not found", close and reopen your terminal — npm global bin path needs a refresh.

// project setup

Create Your Project Folder & Input Files

"A place for everything, everything in its place. Unless you're a developer, in which case everything's on the Desktop." 🗂️

Create a clean project folder. We'll build a workflow where Claude reads some raw meeting notes, summarises them, and writes a to-do list to a new file. Classic, useful, and impressive at demos.

PowerShell — scaffold the project
# Create project directory and navigate into it
mkdir C:\Users\$env:USERNAME\Documents\my-agent
cd C:\Users\$env:USERNAME\Documents\my-agent

# Create an input file with raw meeting notes
New-Item -Name "meeting_notes.txt" -ItemType "File"
Add-Content "meeting_notes.txt" "Meeting: Q3 Planning. Attendees: Sarah, Dev, Priya.
Action items: Launch new dashboard by Aug 15, fix login bug,
review pricing page copy, schedule user interviews."

# Create the CLAUDE.md — this is Claude's instruction manual
New-Item -Name "CLAUDE.md" -ItemType "File"

Now open CLAUDE.md in Notepad (or VS Code) and add this content. This file tells Claude who it is, what it's allowed to do, and how to behave in this project — think of it as Claude's employee handbook, but one it actually reads.

CLAUDE.md — agent instructions
# Agent: Meeting Notes Processor

## Role
You are a helpful productivity agent. You read meeting notes,
extract action items, and write structured summaries.

## Rules
- Only read files in this project directory
- Write output to files named clearly (e.g. summary_output.md)
- Be concise. Nobody reads novels in Slack.
- Format todos as a numbered list with owners if mentioned
ℹ️ CLAUDE.md: Claude Code reads this automatically when launched from the folder. It's how you configure agent behaviour without changing your prompt every time. Think of it as the world's most obedient config file.

Write Your Multi-Step Agent Prompt

"Talking to an AI is like writing a wish for a genie — be specific, or you'll get exactly what you asked for and nothing like what you wanted." 🧞

Create a task.txt file with your full agentic prompt. This is what Claude will execute step-by-step. Unlike a single-shot prompt, an agentic prompt tells Claude to plan, execute multiple sub-tasks, and produce file outputs.

PowerShell — create the task prompt file
New-Item -Name "task.txt" -ItemType "File"
Add-Content "task.txt" "Please do the following:
1. Read the file meeting_notes.txt
2. Extract all action items and owners
3. Write a clean markdown summary to summary_output.md
4. Write a prioritised todo list to todos.md with due dates estimated"

Here's what a well-written agentic prompt looks like (and why it works). Notice it's specific about inputs, outputs, and format — no vague hand-waving allowed.

task.txt — full example (paste this in)
Please do the following in order:

1. READ meeting_notes.txt from the current directory

2. EXTRACT all action items. For each item, identify:
   - The task description
   - The owner (if mentioned)
   - Any deadline (if mentioned)

3. WRITE a file called summary_output.md with:
   - A one-paragraph executive summary
   - A formatted table of action items

4. WRITE a file called todos.md with:
   - A numbered priority list
   - Estimated due dates if not explicit
   - A note if any task is missing an owner

When done, print a one-line confirmation: "✓ Workflow complete. 2 files written."
  • ✓ Prompt lists steps numerically — Claude treats this as a plan
  • ✓ Specifies exact filenames for output — no guessing
  • ✓ Tells Claude what format each output should be in
  • ✓ Ends with a completion signal — great for automation
✓ Pro tip: The more specific your steps, the less "creative" Claude gets with the output format. Creativity is great for poetry. Not so great for structured data files your scripts depend on.

// run & verify

Launch the Agent & Check Your Outputs

"Running an AI agent for the first time is like sending your intern to do a task unsupervised. Mostly it goes well. Sometimes there's a surprise." 🚀

Navigate to your project folder in the terminal and run Claude Code. Pass your task prompt as the --print argument or pipe it from the file. Claude will read your project, pick up CLAUDE.md, and execute the workflow autonomously.

PowerShell — run the agent
# Navigate to project folder (skip if already there)
cd C:\Users\$env:USERNAME\Documents\my-agent

# Run Claude Code with your task prompt piped from file
Get-Content task.txt | claude --print

# Or run interactively (Claude will ask clarifying questions)
claude

# Or pass the task directly as a string
claude --print "Read task.txt and execute the workflow inside it"

Once it finishes, verify your outputs. You should see two new files in the folder. If you don't — check the error message, check your API key, and check if Claude went off on a creative tangent (it happens).

PowerShell — verify outputs
# List files in the project directory
Get-ChildItem -Name

# Expected output should include:
# CLAUDE.md, meeting_notes.txt, task.txt
# summary_output.md  ← new!
# todos.md           ← new!

# Read the summary
Get-Content summary_output.md

# Read the todo list
Get-Content todos.md
✓ It worked! You now have an agentic workflow. Claude read a file, reasoned about the content, made decisions, and wrote structured outputs — all autonomously. You have officially entered the future. You're welcome.
⚠️ If something went wrong: Common culprits: API key not set (check echo $env:ANTHROPIC_API_KEY), typo in file path, or Claude creatively renamed your output file. Claude Code shows detailed logs — read them. They're surprisingly helpful.
// putting it all together

One-shot setup script

Feeling lazy? (Respect.) Here's a single PowerShell script that does Steps 2–4 in one shot. Paste into PowerShell, run it, and skip straight to the victory lap.

setup-and-run.ps1 — full automated setup
# ─── Claude Code Agentic Workflow — Quick Setup ───────────────────

# Step 1: Make sure Claude Code is installed
npm install -g @anthropic-ai/claude-code

# Step 2: Create and enter project folder
mkdir $env:USERPROFILE\Documents\my-agent -ErrorAction SilentlyContinue
cd $env:USERPROFILE\Documents\my-agent

# Create input file with sample meeting notes
@"
Meeting: Q3 Planning. Attendees: Sarah, Dev, Priya.
Action items: Launch new dashboard by Aug 15, fix login bug (Dev),
review pricing page copy (Sarah), schedule user interviews (Priya).
"@ | Out-File meeting_notes.txt -Encoding utf8

# Create CLAUDE.md — agent instruction manual
@"
# Agent: Meeting Notes Processor
## Role
You are a helpful productivity agent.
You read meeting notes, extract action items, and write structured summaries.
## Rules
- Only read files in this project directory
- Write output to clearly named files
- Format todos as a numbered list with owners
"@ | Out-File CLAUDE.md -Encoding utf8

# Step 3: Write the multi-step task prompt
@"
Please do the following in order:
1. READ meeting_notes.txt
2. EXTRACT action items with owners and any deadlines
3. WRITE summary_output.md with a summary + formatted action item table
4. WRITE todos.md with a priority list and estimated due dates
Print "Done!" when complete.
"@ | Out-File task.txt -Encoding utf8

# Step 4: Run the agent!
Write-Host "🚀 Launching Claude Code agent..." -ForegroundColor Green
Get-Content task.txt | claude --print

# Verify outputs
Write-Host "`n📁 Files in project folder:" -ForegroundColor Cyan
Get-ChildItem -Name

Write-Host "`n✅ Done! Check summary_output.md and todos.md" -ForegroundColor Yellow
