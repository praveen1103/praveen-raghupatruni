02 🔑

Get an API Key (and Immediately Expose It)

Grab an API key from OpenAI (or Anthropic, or Groq, or wherever the cool kids are today). The headfirst move is to hardcode it directly into your script, push it to GitHub, and find out 6 minutes later that bots scraped it. Use .env files instead. Learn from our collective trauma.

🚨 If your key starts with "sk-" and ends up on GitHub, you will get an email. It will not be fun.
# .env file (add this to .gitignore immediately)
OPENAI_API_KEY=sk-your-key-goes-here-not-on-github

# In your Python file:
from dotenv import load_dotenv
import os

load_dotenv()
api_key = os.getenv("OPENAI_API_KEY")
# Congrats, you are now a "security engineer"

Choose Your LLM Brain (The Actual Thinking Part)

Pick a Large Language Model to power your agent's "intelligence." Think of it as choosing the brain for your Frankenstein. GPT-4, Claude, Gemini — they're all smart, slightly unhinged, and will confidently answer questions they have no business answering. Wire one up.

🤔 The LLM is like a very enthusiastic intern. Brilliant? Yes. Will it make stuff up? Absolutely.
from langchain_openai import ChatOpenAI

# Initialize the brain
llm = ChatOpenAI(
    model="gpt-4o",
    temperature=0.7,  # 0 = robot, 1 = chaos gremlin
    api_key=api_key
)

# Quick sanity check

print(response.content)  # Spoiler: it'll say no. Suspiciously quickly.

04 🛠️

Give It Tools (So It Can Actually DO Things)

A brain without hands is just a brain. Tools let your agent search the web, run code, read files, call APIs — basically everything you told your parents you could do in a job interview. Define Python functions and decorate them so LangChain knows they exist.

🔧 This is where your agent graduates from "chat bot" to "thing that can accidentally email your boss."
from langchain.tools import tool

@tool
def calculate(expression: str) -> str:
    """Evaluates a math expression. E.g. '2 + 2'"""
    try:
        return str(eval(expression))  # yes eval, we're going fast
    except Exception as e:
        return f"Math broke: {e}"

@tool
def get_weather(city: str) -> str:
    """Gets current weather for a city"""
    return f"It is definitely raining in {city}. It's always raining."

tools = [calculate, get_weather]

05 🎭

Write a System Prompt (Give It a Personality)

The system prompt is your agent's soul. It defines who it is, what it does, and why it exists on this planet. Spend 40% of your total project time here writing, rewriting, and arguing with yourself about how to phrase "be helpful but don't be weird."

🎭 Your system prompt is like writing a dating profile for a robot. Every word matters. None of them are enough.
from langchain_core.prompts import ChatPromptTemplate, MessagesPlaceholder

system_prompt = """You are AgentX, a helpful AI assistant with tools.
You are efficient, friendly, and slightly sarcastic (but in a charming way).
When you don't know something, admit it — unlike certain humans.
Always use tools when they are relevant. Don't guess when you can calculate.
Under no circumstances should you start a sentence with 'Certainly!'"""

prompt = ChatPromptTemplate.from_messages([
    ("system", system_prompt),
    MessagesPlaceholder(variable_name="chat_history"),
    ("human", "{input}"),
    MessagesPlaceholder(variable_name="agent_scratchpad"),
])

06 ⚙️

Assemble the Agent (Frankenstein Moment)

Glue the brain, the tools, and the prompt together into an agent executor. This is the ReAct loop — the agent Reasons, takes an Action, observes the result, and repeats until it has an answer or hits your token limit, whichever comes first.

⚡ "It's alive!" — You, approximately 2 seconds before it enters an infinite loop and burns through your API credits.
from langchain.agents import create_openai_tools_agent, AgentExecutor
from langchain_community.chat_message_histories import ChatMessageHistory

# Bind tools to LLM
agent = create_openai_tools_agent(llm, tools, prompt)

# Wrap in executor (this is the "run the loop" part)
agent_executor = AgentExecutor(
    agent=agent,
    tools=tools,
    verbose=True,     # prints its "thinking" — great for debugging, haunting
    max_iterations=10  # prevent infinite loops (set this, trust me)
)

# Add memory so it doesn't forget you mid-conversation
memory = ChatMessageHistory()

print("🤖 Agent is alive. It is your problem now.")

Run It & Watch the Magic / Chaos Unfold

Fire it up. Talk to it. Watch in amazement as it uses your tools, reasons through problems, and occasionally decides to do something completely unexpected. Add a simple loop for a CLI chat interface, or slap a Gradio/Streamlit UI on it and call it a "product."

🎉 You've officially built an AI agent. Go update your LinkedIn. "Built production AI systems" — close enough.
from langchain_core.messages import HumanMessage, AIMessage

print("🤖 AgentX: Hello. I am ready. Please don't ask me to do your taxes.")

while True:
    user_input = input("You: ").strip()
    if user_input.lower() in ["quit", "exit", "bye"]:
        print("🤖 AgentX: Goodbye. It was statistically probable knowing you.")
        break

    response = agent_executor.invoke({
        "input": user_input,
        "chat_history": memory.messages
    })

    answer = response["output"]
    memory.add_user_message(user_input)
    memory.add_ai_message(answer)

    print(f"🤖 AgentX: {answer}\n")
